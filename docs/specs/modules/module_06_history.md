# Module 06 Specification: Chat History Subsystem (`history`)

## Overview

Module 06 (`history`) constitutes the central conversation stage of Telegram Desktop reconstructed in pure, idiomatic Rust with GPUI. It encompasses the complete message transcript pipeline: `HistoryWidget` container, `History` thread state, `HistoryItem` models, `HistoryView::Element` message bubble layout hierarchy, virtualized scroll rendering with floating date badges, rich media blocks (photos, videos, waveforms, voice notes, stickers, service boxes, polls, games, TON transfers, unsupported notices), full-duplex reaction selectors and particle effects, quoted reply anchors, pinned message banners, voice recording hold-to-record gesture state machines, and context menu actions.

The target Rust/GPUI architecture cleanly separates domain thread models (`crates/gpui_telegram_client/src/history/`) from GPUI rendering widgets (`crates/gpui_telegram_desktop/src/views/stage/`) and theme tokens (`crates/gpui_telegram_desktop/src/theme/`), decomposing monolithic Qt widgets (`history_widget.cpp`, `history_inner_widget.cpp`) into cohesive GPUI submodules wired directly into `ConversationStage`.

## 1. Executive Summary & Architecture Overview

The Chat History subsystem is the core operational view of Telegram Desktop. It processes incoming messages, PTS sequence gaps, media downloads, voice notes, reaction bursts, and interactive bot keyboards. The subsystem is structured into 8 cohesive functional slices:
1. **Core Widgets & State Management**: `HistoryWidget`, `HistoryInnerWidget`, `History`, pagination engine, viewport virtualization, unread indicators, floating date headers, and streamed drafts.
2. **History Item Models, Components & Admin Log**: `HistoryItem`, message edits/revocations, bitwise flag conversions, reply markup button grids, selection math, and audit filters.
3. **History View Element Base & Bubble Layout Hierarchy**: `HistoryView::Element`, `HistoryView::Message`, bubble width calculation, text layout elision, bottom info geometry, delivery ticks, and floating reply buttons.
4. **History View List Widget, Virtual Scrolling & Navigation Bars**: `HistoryView::ListWidget`, pinned message cycling, ID projections, real-time translation FSM, read metrics tracker, and group members controller.
5. **History Basic Media Views**: Photos, documents, voice notes with 100-bar waveforms, grouped media mosaics, stickers, animated GIFs, and spoiler particle masks.
6. **History Rich Media Views**: Service boxes (Telegram Star Gifts, Premium Gifts), WebRTC call cards, invoices, polls with rounding tiebreakers, games, TON transfers, and unsupported notices.
7. **Reactions, Comments & Emoji Interactions**: Floating reaction picker, reaction button state machine, flyout animation FSM, voice transcription button, and paid star reactions.
8. **History View Controls & Interaction Overlays**: Voice note hold-to-record gesture, cancel swipe threshold, character limitation warnings, compose AI sparkle indicator, draft sync FSM, and multi-forward option cycling.
