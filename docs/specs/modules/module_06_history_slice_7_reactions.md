## 2. Upstream C++ Deep Logic & Architecture Analysis

### 2.1 Reaction Button State Machine & Geometry Math
In `history_view_reactions_button.cpp:L290-L313`, the corner button scales and fades through four states:
- `Hidden`: Scale = `1/3` (0.3333), Opacity = `0.0`.
- `Shown`: Scale = `2/3` (0.6667), Opacity = `1.0`.
- `Active`: Scale = `1.0`, Opacity = `1.0`.
- `Inside`: Scale = `1.0`, Opacity = `1.0`, button expands vertically to reveal all reactions in the strip.

The opacity formula normalizes the scale:
$$\text{Opacity}(\text{scale}) = \min\left(1.0, \frac{\text{scale} - 1/3}{2/3 - 1/3}\right)$$

Animation timings:
- `kToggleDuration`: 120ms (scale in/out)
- `kActivateDuration`: 150ms (hover state change)
- `kExpandDuration`: 300ms (expansion to reveal reactions)
- `kCollapseDuration`: 250ms (collapse back to pill)
- `kButtonExpandDelay`: 25ms
- `kButtonHideDelay`: 300ms

### 2.2 Inline List Sorting & Tag Geometry
In `history_view_reactions.cpp:L190-L206`, reactions beneath a message bubble are sorted with strict precedence:
1. **Paid Star Reactions** (`id.paid() == true`): Always ordered first at index 0.
2. **Count Descending**: `count - (my ? 1 : 0)` (subtracting user's own reaction to reflect peer consensus).
3. **Catalog Index Tie-Breaker**: The default catalog order in `Data::Reactions::All`.

For tags (`history_view_reactions.cpp:L48-L75`), each tag pill has an arrow tip:
- Right arrow offset: `reactionInlineTagArrow` (5px)
- Right corner radius: `reactionInlineTagRightRadius` (4px)
- Left corner radius: `reactionInlineTagLeftRadius - rradius` (10px)
