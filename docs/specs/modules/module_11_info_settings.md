## Architectural Clusters & State Machines

### 1. Info Drawer Subsystem Architecture (`Telegram/SourceFiles/info/*`)
The Info Drawer is anchored by `Info::WrapWidget` which manages a 320px collapsible right panel within the desktop main window. The drawer supports a stacked navigation model with `Info::Memento` history state management.
- **Profile & Channel Header**: Renders user/channel avatar with real-time status badges, bio/description, username pills with click-to-copy, phone numbers, and notification toggles.
- **Shared Media Hub**: Tabbed media browser (Photos, Videos, Files, Audio, Shared Links, Voice Messages, GIFs) with infinite virtual scrolling, grid zooming, and pre-buffering.
- **Members & Administration**: Full member search, role badges (Owner, Admin, Member, Restricted), granular permissions matrix, and pending join requests approval queue.
- **Statistics & Monetization**: Channel growth charts, recent message views, star balance pill, monetization earnings breakdown, and channel boost progression.
- **Stories & Peer Gifts**: Story grid viewer with pin/unpin ordering, star gift collections, and reaction list filters.

### 2. Settings Subsystem Architecture (`Telegram/SourceFiles/settings/*`)
The Settings Subsystem provides a unified, searchable preferences navigation controller (`Settings::Main`) hosting multiple specialized sections:
- **Settings Core & Information**: Profile editing, username reservation, bio update, active sessions inspection, and fast indexed search.
- **Privacy & Security**: Two-Factor Authentication (2FA) cloud password, passcode lock, auto-lock timer, active web sessions, and granular privacy matrices (Phone Number, Last Seen, Profile Photo, Forwarded Messages, Calls, Groups & Channels).
- **Chat Settings & Appearance**: Chat theme presets (Day, Night, Tinted), custom background wallpaper, message text font size slider (12px–24px), emoji style, and sticker animations.
- **Notifications & Sounds**: Desktop toast notifications, badge counter modes (all unread vs unread chats), sound selection, flash taskbar toggle, and notification preview.
- **Folders & Filters**: Custom chat folder creation, include/exclude rules, folder reordering, and recommended folder suggestions.
- **Advanced & Local Storage**: Auto-download thresholds, disk cache size limits, clear cache dialog, connection type (Direct, SOCKS5, HTTP, MTProto Proxy), and system integration.
- **Business Tools**: Away messages, greeting messages, quick replies with shortcut keys, chatbot integrations, and business working hours.
